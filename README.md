# Bank Loan Analysis Dashboard
A comprehensive Excel dashboard designed to monitor and analyze bank loan data to improve lending decisions and risk management.

## 📊 Key Insights & KPIs
*   *Total Loan Applications:* Tracking the volume of applications over time.
*   *Total Funded Amount:* Monitoring the total capital disbursed.
*   *Total Amount Received:* Tracking repayments to assess cash flow.
*   *Average Interest Rate:* Analyzing the cost of borrowing across different loan grades.
*   *Loan Status Distribution:* Visualizing the ratio of 'Good' vs. 'Bad' loans to identify credit risk.

## 🛠️ Tools Used
*   *Excel:* Data cleaning, Pivot Tables, and DAX-style measures.
*   *Power Query:* For automated data processing.
*   *Data Visualization:* Interactive charts, slicers, and conditional formatting.

## 📁 How to View
1. Download the BANK LOAN REPORT.xlsx file from this repository.
2. Open in Microsoft Excel (Desktop version recommended for full functionality)
